Tách hóa đơn PDF theo tên đơn vị

Thả file PDF gồm nhiều hóa đơn. Mỗi hóa đơn được tách thành một file riêng, đặt tên theo dòng "Tên đơn vị" in trên hóa đơn, rồi tải về một file ZIP.

🔒 Bảo mật dữ liệu PDF
Kéo thả file PDF vào đây hoặc bấm để chọn Hóa đơn điện tử dạng chữ (MISA, VNPT, Viettel…). File scan dạng ảnh chưa hỗ trợ.
Đặt tên file theo Bấm để chọn thông tin, bấm lần nữa để bỏ. Thứ tự là thứ tự bạn bấm.
Tên file sẽ là ví dụ minh họa
Tùy chỉnh nâng cao

Có thể gõ thêm chữ cố định, ví dụ HD_{so}_{donvi}. Các mã: {so} {donvi} {mst} {ngay} {kyhieu}.
