Tách hóa đơn PDF theo tên đơn vị

Thả file PDF gồm nhiều hóa đơn. Mỗi hóa đơn được tách thành một file riêng, đặt tên theo dòng "Tên đơn vị" in trên hóa đơn, rồi tải về một file ZIP.

🔒 File được xử lý ngay trên máy bạn, không tải lên máy chủ

Kéo thả một hoặc nhiều file PDF vào đây, hoặc bấm để chọn Hóa đơn điện tử dạng chữ (MISA, VNPT, Viettel…). Đọc được cả file scan (dạng ảnh), chậm hơn một chút và cần mạng ở lần đầu.
Đặt tên file theo Bấm để chọn thông tin, bấm lần nữa để bỏ. Thứ tự là thứ tự bạn bấm.
Tên file sẽ là ví dụ minh họa
Tùy chỉnh nâng cao

Có thể gõ thêm chữ cố định, ví dụ HD_{so}_{donvi}. Các mã: {so} {donvi} {mst} {ngay} {kyhieu}.

Nhãn bổ sung cho mẫu hóa đơn khác (không bắt buộc). Tool đã nhận sẵn nhãn của MISA, VNPT, Viettel, BKAV… Nếu mẫu của bạn ghi khác, gõ đúng chữ in trên hóa đơn, nhiều nhãn cách nhau bằng dấu phẩy.

Danh sách khách hàng (nên có khi dùng file scan) Dán 2 cột từ Excel: MST và Tên chuẩn. Khi đọc được MST trên hóa đơn, tool lấy tên chuẩn để đặt tên file, tránh tên bị sai dấu khi đọc file scan. Danh sách được lưu trên trình duyệt của bạn. Chưa có khách hàng nào.

Chương trình tìm các nhãn như "Tên đơn vị", "Mã số thuế", "Số", "Ngày … tháng … năm", "Ký hiệu", "Tổng tiền thanh toán" trên từng trang (nhận nhiều mẫu hóa đơn). Hóa đơn dài nhiều trang được gộp vào một file theo số hóa đơn. Tên trùng nhau được thêm (2), (3)… Với file scan: dòng vàng nên xem lại tên, dòng đỏ cần kiểm tra lại.

Kéo thả file PDF cần nén vào đây hoặc bấm để chọn Hợp nhất với file scan (tài liệu, hợp đồng, hồ sơ). Trang PDF dạng chữ được giữ nguyên. File dưới 20 MB: miễn phí.
